# 플레어 포지 — 거듭제곱의 불꽃
중학교 2학년 지수법칙 퍼즐. 이웃한 돌 두 개를 순서대로 선택하고 곱하거나 나누어 목표 하나를 남깁니다. 결과는 두 번째 자리에 남고 빈칸은 건널 수 없습니다. 나눗셈은 결과의 지수가 음수가 되지 않는 범위이며 같은 거듭제곱끼리 나누면 1입니다.

`npm test`, `npm run build`, `npm start`. 진행은 이 브라우저에 저장됩니다. 첫 안내는 별도 연습이며 새로 시작해도 기존 진행을 보존합니다. 음악은 재생 버튼으로 시작합니다. 재미·학습 효과에 대한 학생 대상 검증은 아직 하지 않았습니다.
